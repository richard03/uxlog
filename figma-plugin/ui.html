Nejprve se připojte k API v záložce Nastavení.

Z Figmy nelze volat přímo backend Flexi (origin null; CORS z API bývá jen pro web). Jsou dva hotové proxy skripty: flexi-proxy-php.php (hostované Flexi API, např. https://uxlog.prokoho.cz/flexi-proxy-php.php) a flexi-proxy-windows.php (lokální Windows API na 127.0.0.1:7842 — spusťte u sebe php -S localhost:8787 -t public a v pluginu zadejte http://localhost:8787/flexi-proxy-windows.php). Starší flexi-proxy.php chová stejně jako PHP varianta.
